Test de Niveles de Estrés

Este test está diseñado para ayudar a las personas a identificar sus niveles de estrés, reconocer posibles detonantes y recibir recomendaciones para manejarlo.

Se recomienda consultar a un psicólogo de confianza para una evaluación más detallada.
